Ma vidéothèque

Choisis entre la gestion de ta vidéothèque et l’export CSV vers Trakt ou Letterboxd.

Cette page et son code sont publics. Les jetons restent en mémoire par défaut. Si tu actives leur mémorisation, ils sont stockés localement sans chiffrement et restent accessibles aux scripts exécutés sur ce site. Le jeton GitHub permet de modifier ton dépôt : limite ses droits à ce seul dépôt, avec une expiration courte, et utilise uniquement un appareil de confiance. Tu peux supprimer les jetons sauvegardés à tout moment.

3. Actualiser les données des films

Repère les fiches dont les données complémentaires sont incomplètes. Les fiches sont d’abord lues depuis GitHub sans solliciter TMDB. Seuls les films incomplets sont actualisés, un par un, avec une pause d’une seconde entre les requêtes. Les modifications sont enregistrées par lots de 50 films pour faciliter la reprise.

4. Initialiser les sagas de mes films vus

Analyse les fiches des films vus pour repérer leurs collections, puis actualise uniquement les sagas absentes ou dont les données datent de plus de 30 jours. Les films sont regroupés par saga : une seule requête TMDB par collection, exécutée séquentiellement avec 700 ms entre deux requêtes. Les fiches de films sont lues depuis le dépôt, sans appel TMDB.

Export vers Trakt et Letterboxd

Les films sont classés du plus récent au plus ancien selon leur date de visionnage. Aucun compte ni jeton n’est nécessaire : les fichiers sont générés dans ton navigateur.

Lecture de ta vidéothèque…

Après téléchargement, importe le fichier depuis Trakt – Import ou Letterboxd – Import. Les fichiers contiennent les dates de visionnage et les notes disponibles. Un seul dernier visionnage par film est exporté, conformément aux données conservées dans ta vidéothèque.

Comparer avec Kodi

Connexion directe à Kodi sur ton réseau local. Comparaison strictement en lecture seule : aucun statut ne sera modifié.

L’adresse IP est mémorisée uniquement dans le navigateur. Port WebSocket par défaut : 9090. Le port HTTP 8080 n’est pas utilisé.

Configuration nécessaire dans Kodi

  1. Dans Paramètres → Services → Contrôle, active « Autoriser le contrôle à distance par des applications sur d’autres systèmes ».
  2. Conserve le port TCP par défaut 9090, sauf modification personnelle.
  3. Vérifie que ton téléphone et Kodi sont sur le même réseau local.

Attention : l’interface de contrôle sur le port 9090 ne possède pas d’authentification. Ne l’expose jamais sur Internet et réserve-la à un réseau local de confiance. Chrome peut demander une autorisation d’accès au réseau local.

Ce produit utilise l'API TMDB mais n'est ni approuvé ni certifié par TMDB.
