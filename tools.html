Export vers Letterboxd

Les films sont classés du plus récent au plus ancien selon leur date de visionnage. Aucun compte ni jeton n’est nécessaire : les fichiers sont générés dans ton navigateur.

Lecture de ta vidéothèque…

Après téléchargement, importe le fichier depuis Letterboxd – Import. Le fichier contient les dates de visionnage et les notes disponibles. Un seul dernier visionnage par film est exporté, conformément aux données conservées dans ta vidéothèque.

Sauvegarde complète de la vidéothèque

Crée un fichier compressé contenant l’index, toutes les fiches détaillées des films et les fichiers de sagas associés. Les notes, dates de visionnage et données TMDB complémentaires sont conservées.

Le fichier est généré dans ton navigateur, sans jeton ni service externe. Tu peux ensuite le déposer manuellement sur Google Drive. Il n’est pas chiffré. L’export vérifie chaque fiche et contrôle que l’index n’a pas changé pendant la sauvegarde.

La sauvegarde n’a pas encore été créée.

Base locale IndexedDB

L’import crée une nouvelle génération de données locale et ne remplace la version active qu’après validation complète. La version précédente est conservée. Les données restent sur ce navigateur et cet appareil.

Toutes les modifications sont enregistrées uniquement dans IndexedDB. Chaque navigateur possède sa propre base : utilise une sauvegarde pour transférer tes données vers un autre appareil.

Détecter les doublons

Les fiches sont regroupées par identifiant TMDB. Aucune suppression n’est effectuée pendant la détection. Dans chaque groupe, choisis d’abord la fiche à conserver ; tu pourras ensuite supprimer les autres.

Comparer avec Kodi

Connexion directe à Kodi sur ton réseau local. Comparaison strictement en lecture seule : aucun statut ne sera modifié. Chaque résultat peut être ignoré ; cette exclusion est conservée dans IndexedDB et s’applique à toutes les rubriques des prochaines comparaisons.

Chargement de l’adresse enregistrée…

L’adresse est conservée dans IndexedDB sur cet appareil après enregistrement. Port WebSocket par défaut : 9090. Le port HTTP 8080 n’est pas utilisé.

Configuration nécessaire dans Kodi

  1. Dans Paramètres → Services → Contrôle, active « Autoriser le contrôle à distance par des applications sur d’autres systèmes ».
  2. Conserve le port TCP par défaut 9090, sauf modification personnelle.
  3. Vérifie que ton téléphone et Kodi sont sur le même réseau local.

Attention : l’interface de contrôle sur le port 9090 ne possède pas d’authentification. Ne l’expose jamais sur Internet et réserve-la à un réseau local de confiance. Chrome peut demander une autorisation d’accès au réseau local.

Ce produit utilise l'API TMDB mais n'est ni approuvé ni certifié par TMDB.
